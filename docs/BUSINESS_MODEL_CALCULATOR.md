# Business Model Calculator

## Quick Calculations

### Input Variables
- **Reward per User**: $0.50 (5,000 G$)
- **App Share**: 50% = $0.25
- **Twilio Cost per User**: $0.065
- **Fixed Costs**: $25/month

### Formula
```
Net Profit per User = App Revenue - Twilio Cost
Break-Even Users = Fixed Costs / Net Profit per User
Monthly Profit = (Users × Net Profit) - Fixed Costs
```

## Break-Even Calculator

```
Break-Even Users = Fixed Costs / (Revenue per User - Cost per User)

Current:
= $25 / ($0.25 - $0.065)
= $25 / $0.185
= 135 users/month

With Premium (5% conversion):
= $25 / ($0.25 + $0.35 - $0.065)
= $25 / $0.535
= 47 users/month
```
